Your Development Tools

Professional Tools for Your First App

As a Developer Dojo ninja, you have access to professional development tools designed for building your first app. Code from anywhere, run full development environments, and access the infrastructure you need to bring your ideas to life.

24/7 Access
Browser-Based IDE

Code Dojo

Your personal cloud IDE powered by Coder-server. Code from any device with full VS Code compatibility, extensions, and integrated terminals. Perfect for building your first web or mobile app. Access at code.ninjahive.org—no local setup required.

Full Desktop Access
Any OS

Virtual Dojo

Complete development environments in your browser via Apache Guacamole. Run Windows, Linux, or specialized setups when your project needs specific tools or OS configurations. Access full desktops at desk.ninjahive.org and vm.ninjahive.org. Powered by KubeVirt.

Testing & Monitoring

App Builder Tools

Everything your first app needs to go from code to production. Hosted databases (PostgreSQL, MongoDB, Redis), containerization for deployment, automated testing pipelines, and monitoring tools. We provide the infrastructure so you can focus on building.
